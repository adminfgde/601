## 三、超前预测（LightGBM vs persistence）

### 1. Köln-Weiden 真实代理真值（厂-网-雨一体化，2017 全年 15min）

用上游 3 个管网液位 + 调蓄液位 + 降雨的滞后特征预测厂前进水流量：

| 超前 | 模型 NSE | 模型 MAE (l/s) | persistence NSE |
|---|---|---|---|
| +60min | **0.942** | 15.4 | 0.839 |
| +120min | **0.809** | 29.4 | 0.623 |
| +180min | **0.677** | 40.0 | 0.424 |

结论：在真实厂-网-雨数据上，"上游管网信号 → 厂前进水"超前 1~3h 预测可行，
且全面显著优于 persistence——方法有效性得到真实数据背书。

### 2. 泰和模拟场景（26 泵站骨架 + 上海实测降雨，5min）

| 目标 | 超前 | 模型 NSE | persistence NSE |
|---|---|---|---|
| 进水流量 | +60min | **0.926** | 0.687 |
| 进水流量 | +120min | **0.922** | 0.140 |
| 进水流量 | +180min | **0.923** | -0.539 |
| COD | +60min | 0.035 | -0.126 |
| COD | +120min | -0.131 | -0.766 |
| COD | +180min | -0.144 | -0.973 |

结论：流量超前 3h 仍保持 NSE≈0.92（persistence 已崩溃至负值），
证明骨架+实测降雨的因果链可被学习。COD 在当前模拟配置下以随机噪声/
冲击为主、确定性结构弱，NSE 接近 0 属于模拟数据本身可预测性上限，
模型仍优于 persistence；后续以 SWMM 水质模块或加强模拟确定性结构改进。

> 诚实性声明：第 2 组是模拟数据上的验证，不代表泰和厂实测性能；
> 真实数据性能证据以第 1 组（Köln 真实数据）为准。

## 四、预警与协同调控（规则引擎演示）

`src/control/warning.py`：按预测进水占厂设计能力比例分四级预警
（蓝 0.6 / 黄 0.8 / 橙 0.95 / 红 1.10），每级绑定调控建议
（加强监视 → 雨前预抽空 → 彭越浦总站错峰 → 全网限流+调蓄）。
2024 汛期 92 天演示：黄色 322 步、橙色 71 步、红色 28 步，
提前量 120min（reports/warning_demo.csv）。

## 复现

```bash
pip install -r requirements.txt
python -m src.data.shanghai_rain                       # 数据融合层
python -m src.simulation.generate --days 92 \
  --rain-csv data/processed/shanghai_rain_10min.csv \
  --rain-start 2024-06-01 --out data/simulated_realrain # 真实降雨驱动场景
python -m src.models.forecast --dataset koeln           # 真实数据方法验证
python -m src.models.forecast --dataset taihe           # 泰和场景迁移
python -m src.control.warning                           # 预警调控演示
```
