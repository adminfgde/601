# 人工运行教程（手把手）

本文教你从零开始手动跑通整个项目，并解释仓库里每个文件是干什么的。

## 〇、环境准备

要求：Python 3.10 及以上（3.10 / 3.11 / 3.12 均可）。

```bash
# 1. 进入项目目录
cd meec8-topic7

# 2. （可选，推荐）创建虚拟环境，避免污染系统 Python
python3 -m venv .venv
source .venv/bin/activate        # Windows 用 .venv\Scripts\activate

# 3. 安装依赖（numpy/pandas/scikit-learn/lightgbm/matplotlib 等）
pip install -r requirements.txt
```

不想手动一步步跑的话，直接：

```bash
bash run_all.sh
```

它会自动完成下面第 1~4 步。以下是手动逐步运行方式。

## 一、生成泰和模拟场景数据（第 1 步）

组委会没有提供时序运行数据，所以管网/泵站/进水时序由模拟器生成：

```bash
python -m src.simulation.generate --days 92 --out data/simulated_realrain
```

- `--days 92`：模拟 92 天（汛期长度），5 分钟一个数据点
- `--out`：输出目录
- 如果你已经跑过 `python -m src.data.shanghai_rain` 得到上海实测雨量
  （需要自行下载上海水务局原始数据，见下文"可选步骤"），可以加：
  `--rain-csv data/processed/shanghai_rain_10min.csv --rain-start 2024-06-01`
  用真实降雨驱动模拟；没有该文件会自动改用合成降雨，不影响跑通。

跑完后 `data/simulated_realrain/` 里会有 9 个 CSV（含拓扑、流量、液位、水质、泵运行等）。

## 二、超前预测模型（第 2 步，核心）

### 2.1 Köln 真实数据验证（证明方法在真实厂网数据上有效）

```bash
python -m src.models.forecast --dataset koeln
```

- 数据集缺失时会自动从 Zenodo（记录 6992694，约 10MB，CC-BY-4.0）下载到
  `data/external/zenodo_6992694_koeln_wtp_network_rain/`
- 用上游 3 个管网液位 + 调蓄液位 + 降雨预测污水厂进水流量
- 期望输出（NSE 越接近 1 越好）：
  - +60min NSE≈0.942、+120min ≈0.809、+180min ≈0.677

### 2.2 泰和模拟场景迁移

```bash
python -m src.models.forecast --dataset taihe
```

- 如果第 1 步没跑，脚本会自动先生成模拟数据
- 预测进水流量、COD/氨氮负荷等，指标写入 `reports/forecast_metrics.json`

常用参数：`--horizons 12 24 36`（超前步数，泰和 5min/步），`--sim-dir` 指定数据目录。

## 三、四级预警与调控建议（第 3 步）

```bash
python -m src.control.warning
```

- 按"预测进水量 / 厂设计能力"比例分四级预警：蓝 0.6 / 黄 0.8 / 橙 0.95 / 红 1.10
- 每级绑定调控建议（加强监视 → 雨前预抽空 → 总站错峰 → 全网限流+调蓄）
- 输出 `reports/warning_demo.csv`，控制台打印各级预警步数统计

## 四、单元测试（第 4 步，验证代码没坏）

```bash
pip install pytest
python -m pytest tests -q     # 期望：7 passed
```

## 五、可选步骤（非必需）

```bash
# 上海水务局雨量/水位数据融合（需先自行下载原始 zip 到 data/external/shgov_water_regime/）
python -m src.data.shanghai_rain

# 批量生成技术报告/PPT 用的全部图表 → reports/figures/
python -m src.viz.make_figures

# 交互式演示看板（浏览器打开，需 streamlit）
streamlit run deliverables/demo/app.py

# 深度模型对比（LSTM vs LightGBM，需另装 PyTorch：pip install -r requirements-optional.txt）
python -m src.models.deep_forecast --horizon-min 120

# 污染冲击异常分类预警
python -m src.models.anomaly

# 极端场景压力测试（设计暴雨 P=5/50/100a + 台风回放）
python -m src.models.stress_test --horizon-min 120

# 降雨预报输入实验（无预报/带噪预报/完美预报对比）
python -m src.models.rain_forecast_exp

# 预警命中评估与效益量化
python -m src.control.benefits --horizon-min 120

# SWMM 在环调度对比（需 pyswmm；先 build_inp 生成 INP 模型）
python -m src.swmm.build_inp --rain-csv data/processed/design_storm_p50_10min.csv --out data/swmm/taihe_p50.inp
python -m src.control.rolling_opt
```

## 六、每个文件/目录是干什么的

### 根目录

| 文件 | 作用 |
|---|---|
| `README.md` | 项目总说明：背景、成果清单、仓库结构、快速开始 |
| `run_all.sh` | 一键复现脚本：依赖安装 → 数据生成 → 预测 → 预警 |
| `requirements.txt` | 必需依赖清单（pip 安装用） |
| `requirements-lock.txt` | 锁定版本的依赖清单（保证完全一致的复现环境） |
| `requirements-optional.txt` | 可选依赖（PyTorch 等深度模型用） |
| `.gitignore` | 忽略自动下载/自动生成的数据目录，避免误提交 |
| `.github/workflows/ci.yml` | GitHub Actions 自动化：每次 push 自动跑单元测试 |

### src/ —— 核心源码

| 文件 | 作用 |
|---|---|
| `src/simulation/generate.py` | 模拟数据生成入口：命令行参数解析，输出拓扑+时序 CSV |
| `src/simulation/topology.py` | 生成管网拓扑骨架（43 节点 / 42 管段 / 6 泵站） |
| `src/simulation/timeseries.py` | 生成时序数据：旱天日变化 + 雨天入流 + 水质 + 泵操作 |
| `src/simulation/config.py` | 模拟参数配置（天数、步长、随机种子、管网规模等） |
| `src/simulation/design_storm.py` | 设计暴雨生成：上海市暴雨强度公式 + 芝加哥雨型 |
| `src/models/forecast.py` | **核心预测模型**：LightGBM 超前 1~3h 点预测 + P10/P90 区间，基线对比（persistence/季节朴素/MLP），Köln 数据自动下载 |
| `src/models/deep_forecast.py` | 深度模型对比：LSTM（PyTorch）vs LightGBM |
| `src/models/anomaly.py` | 污染冲击异常分类预警（LightGBM 分类器识别冲击事件） |
| `src/models/stress_test.py` | 极端场景压力测试：设计暴雨/台风场景跨场景泛化 |
| `src/models/rain_forecast_exp.py` | 降雨预报输入实验：无预报/带噪/完美预报三种配置对比 |
| `src/control/warning.py` | 四级预警规则引擎 + 调控建议输出 |
| `src/control/benefits.py` | 预警命中评估与效益量化（预抽空、削峰、调蓄拦截） |
| `src/control/rolling_opt.py` | SWMM 在环调度策略对比（静态/规则/预见性滚动调度） |
| `src/swmm/build_inp.py` | 概化 SWMM 模型（INP 文件）构建，供 rolling_opt 使用 |
| `src/data/shanghai_rain.py` | 上海水务局雨量/水位原始数据清洗对齐（需自行下载原始数据） |
| `src/viz/make_figures.py` | 批量生成报告/PPT 的全部图表 |
| `src/utils/` | 公共工具（预留） |

## 七、常见问题

1. **`No module named lightgbm`** → 没装依赖，先 `pip install -r requirements.txt`
2. **Köln 下载慢/失败** → 手动到 https://zenodo.org/records/6992694 下载
   `wtp_network_rain.csv`，放到 `data/external/zenodo_6992694_koeln_wtp_network_rain/` 下
3. **`src.data.shanghai_rain` 报 `No objects to concatenate`** → 正常，说明没有
   上海水务局原始数据；这步是可选的，跳过即可，模拟器会用合成降雨
4. **想改预测目标/超前时长** → `python -m src.models.forecast --dataset taihe --horizons 12 24 36`（5min/步，12 步=1 小时）
