# 技术报告大纲（≥15 页，初赛 2026-09-15 截止）

> 主题七：基于厂站网一体化的污水厂进厂水量水质超前感知与协同调控模型

## 1. 绪论（1.5 页）
- 背景：合流制排水系统雨天入流冲击、厂前进水波动对工艺稳定性的影响
- 泰和污水厂系统概况：苏州河沿线 26 座泵站（Date1），彭越浦总站汇流，总设计能力 40.5 m³/s
- 问题定义："感知—预测—预警—预控"闭环，超前 1~3h 预测进厂水量水质并给出协同调控建议

## 2. 数据体系（2.5 页）★评分重点
- 真实数据（下载入库并标注来源，引 docs/数据说明.md）：
  1. Date1 官方骨架（泵站能力/服务范围/系统图）
  2. 上海官方观测：水务局「水情信息」52 站 10~15min 雨量/水位/潮位（2021–2025，1150 万行）、NOAA/ERA5 气象、CNEMC 断面水质
  3. 国际公开真实数据集：Köln-Weiden 厂-网-雨一体化、Graz、Milan、BSM2 等 17 类
- 模拟数据：生成方式与参数设定（拓扑/旱天规律/降雨径流/输送延迟/水质/异常冲击）
- 真实与模拟数据的对应关系与使用声明（引 DATA_CATALOG）

## 3. 厂站网一体化建模（3 页）
- 管网拓扑概化：43 节点/42 管段/6 级泵站结构（对应 Date1 骨架）
- 物理机制：旱天双峰日变化、RDII 入流入渗（径流系数 0.35）、输送延迟（0.8 m/s）、初期冲刷、稀释效应、泵站前池液位启停逻辑
- 上海实测降雨耦合：2024 汛期 92 天场景（雨时占比 20.9%）

## 4. 超前预测模型（3.5 页）★核心
- 特征工程：多滞后 + 差分 + 滑动均值 + 时刻特征
- 模型：LightGBM（对比 persistence 基线；可扩展 LSTM 消融）
- 真实数据验证（Köln）：+1h NSE 0.942 / +2h 0.809 / +3h 0.677
- 泰和场景迁移：流量 +3h NSE 0.92；COD 可预测性分析与改进方向
- 提前量-精度权衡曲线、误差分析

## 5. 预警与协同调控（2.5 页）
- 四级预警（蓝/黄/橙/红，按设计能力占比 0.6/0.8/0.95/1.10）
- 规则化调控策略：雨前预抽空 → 错峰开泵 → 限流+调蓄
- 2024 汛期演示：橙红预警 99 步，提前量 120min
- 与 26 泵站能力约束的一致性
